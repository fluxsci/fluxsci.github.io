# Project rules

- This is an illustrative showcase, not a scientific publication.
- Keep all wording and figure compositions original. Never copy research-paper prose or figures.
- Use only openly available public source data; retain identifiers, addresses and checksums.
- Never imply that anatomical meshes and activity measurements come from a matched specimen unless the source confirms it.
- Preserve user edits. Website export reads this project; project initialization refuses to overwrite it.
- Source plots live in plots/; use Flux for linked asset updates and composition edits.
